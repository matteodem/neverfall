# ⚔️ Heroes of Neverfall

**Heroes of Neverfall** is a browser-based 3D MMORPG currently in active development.

The goal is to create a lightweight online RPG that runs directly in the browser, with real-time multiplayer, action combat, progression, group content, and an expanding world.

> 🚧 Heroes of Neverfall is still in active development. Features, visuals, balancing, assets, systems, and the project name may change over time.

## ✨ Current Features

- Real-time multiplayer
- Action combat
- Three playable classes: Warrior, Ranger, and Mage
- Character progression up to Level 20
- Quests, hunts, bosses, rare enemies, and dynamic world events
- Loot, equipment, consumables, and a vendor shop
- Parties and instanced dungeons
- Mounts
- Achievements
- Minimap and world map
- Character creation with basic appearance customization
- Chat
- Mobile support
- Persistent progression

## 🛠️ Tech Stack

- **Meteor.js** — backend and authentication
- **MongoDB** — persistent game data
- **React** — UI and HUD
- **Babylon.js** — 3D rendering
- **Colyseus** — real-time multiplayer server
- **Zustand** — client-side state
- **Tailwind CSS** + **DaisyUI** — UI styling

The project currently uses JavaScript rather than TypeScript.

## 🎮 Gameplay

Players create a character, choose a class, explore the world, fight enemies, complete quests and events, collect loot, improve their character, group with other players, and take on dungeon and boss content.

## 🌐 World Events

Dynamic world events bring shared activities into the open world.

Current examples include:

- **Wolf Invasion**
- **Forest Giant Awakening**

## 🏰 Dungeons

Neverfall supports instanced dungeon content for solo players and parties.

The dungeon system supports multiple dungeon configurations, enemy groups, mini-bosses, final bosses, rewards, and returning to the open world.

## 🚀 How to Run

First, install Meteor:

[Install Meteor](https://docs.meteor.com/about/install.html)

Then run:

```sh
cd game
meteor npm install
meteor run
```

The game should then be available at:

```text
http://localhost:3000
```
