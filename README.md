# ⚔️ Heroes of Neverfall

**Heroes of Neverfall** is the working title for a browser-based MMORPG currently in active development.

The goal is to create a lightweight online RPG that runs directly in the browser, featuring real-time multiplayer, action combat, character progression, quests, exploration, and an expanding game world.

> 🚧 The project is currently in an early MVP stage. Features, visuals, balancing, assets, and systems may change during development.

---

## ✨ Current Features

- 🌍 3D browser-based game world
- 👥 Real-time multiplayer
- ⚔️ Action combat
- ❤️ Health, healing, death, and respawn
- 🐗 Enemies with simple AI
- ⭐ XP and level progression
- 📈 Level-based health, damage, and healing scaling
- 📜 Basic quest system
- 🧙 Character creation and character selection
- 🎨 Basic character appearance options
- 🎒 HUD and basic inventory UI
- 🌲 Procedurally created environments
- 💾 Persistent character progression

---

## 🛠️ Tech Stack

Heroes of Neverfall is built with:

- **Meteor.js** — application backend and authentication
- **MongoDB** — persistent character and game data
- **React** — UI and HUD
- **Babylon.js** — 3D rendering and game world
- **Colyseus** — real-time multiplayer game server
- **Zustand** — client-side state management
- **Tailwind CSS** — UI styling
- **DaisyUI** — reusable UI components

---

## 🎮 Gameplay

The current gameplay loop is intentionally simple:

1. Create or select a character
2. Enter the game world
3. Explore the environment
4. Fight enemies
5. Complete quests
6. Earn XP
7. Level up
8. Become stronger

The MVP focuses on getting this core loop working and stable before adding larger systems such as advanced combat, equipment, dungeons, crafting, trading, and additional world content.

---

## 🚀 How to Run

First, install Meteor:

[Install Meteor](https://docs.meteor.com/about/install.html)

Then run:

```sh
cd game
meteor npm install
meteor run
```

The application should then be available at:

```
http://localhost:3000
```
